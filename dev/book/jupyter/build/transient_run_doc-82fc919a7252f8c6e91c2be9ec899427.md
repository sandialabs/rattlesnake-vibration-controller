(sec:transient_run:environment_control_groupbox)=
* [**Signal Level**](#fig:transient_run:test_level_selector) A scale factor applied to the target signals.
* [**Repeat Signal**](#fig:transient_run:repeat_signal_checkbox) If checked, the signal will continually repeat until manually stopped.  If unchecked, the environment will automatically stop when the signal is done.
* [**Start Environment**](#fig:transient_run:start_test_button) Start the environment to control to the desired transient signal
* [**Stop Environment**](#fig:transient_run:stop_test_button) Stop the environment manually.  The signal will ramp down using the Ramp Time specified on the Environment Definition tab to prevent a hard stop that could potentially damage test equipment or articles.
* [**Save Current Control Data**](#fig:transient_run:save_current_control_data_button) Opens a file dialog to save the current control data to a file.

* [**Outputs Plot**](#fig:transient_run:output_signal_plot) Displays the recently acquired output signals.  For long transients, displaying too much data on the screen at once can cause performance issues, so the amount of data plotted can be specified with the Display Duration selector.

(sec:transient_run:data_display_groupbox)=

* [**Create Window**](#fig:transient_run:create_window_button) Create a window to show the signal specified by the Control Channel selector

* [**Tile All Windows**](#fig:transient_run:tile_windows_button) Tiles all visualization windows across the main monitor
* [**Close All Windows**](#fig:transient_run:close_windows_button) Closes all existing visualization windows
