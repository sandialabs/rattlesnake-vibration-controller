(sec:sine_run:control_updates_groupbox)=
* [**Drive Updates**](#fig:sine_run:control_updates_plot) Shows the updates that the controller is applying to the open-loop drive signal based on error correction. The plot is shown in the complex plane with real part on the horizontal axis and imaginary part on the vertical axis.  The drive updates shown correspond to those applied to the selected drive channel and sine tone in the Drive Signal Selector box.


(sec:sine_run:environment_control_groupbox)=
* [**Signal Level**](#fig:sine_run:test_level_selector) Runs the control at a modified test level.  Often used to investigate control accuracy at a lower level without potentially damaging the test article.
* [**Partial Environment**](#fig:sine_run:partial_environment_selector) If checked, this will enable the user to select only specific sine tones or specific time ranges over which to run the environment, which can be useful to investigate poor control in specific tones or over specific modes of the structure.
* [**Partial Environment Tone Selector**](#fig:sine_run:partial_environment_tone_selector) Only tones selected in this list will be run if the Partial Environment checkbox is checked.
* [**Partial Environment Start Time**](#fig:sine_run:start_time_selector) If the Partial Environment checkbox is checked, the environment will start at the time specified inthis box.
* [**Partial Environment End Time**](#fig:sine_run:stop_time_selector) If the Partial Environment checkbox is checked, the environment will end at the time specified inthis box.
* [**Start Environment**](#fig:sine_run:start_test_button) Starts the environment controlling to the specified sine tones.
* [**Stop Environment**](#fig:sine_run:stop_test_button) Stops the environment manually.
* [**Save Control Data**](#fig:sine_run:save_control_data_button) Saves the current control data from the test.


(sec:sine_run:amplitude_groupbox)=
* [**Response Amplitude Plot**](#fig:sine_run:amplitude_plot) Plots the response amplitude compared to the specification for the selected control channel and sine tone.  Additionally plots warning and abort limits if specified.


(sec:sine_run:phase_groupbox)=
* [**Response Phase Plot**](#fig:sine_run:phase_plot) Plots the response phase compared to the specification for the selected control channel and sine tone.


(sec:sine_run:channel_selector_groupbox)=
* [**Response Signal Selector**](#fig:sine_run:signal_selector) Shows the decibel error of each control signal (column) and sine tone (row). Selecting a cell will update the signals plotted in the Response Amplitude and Response Phase plots. Cells will be highlighted in yellow if they hit warning limits and highlighted in red if they hit abort limits.


(sec:sine_run:groupBox)=
* [**Drive Signal Selector**](#fig:sine_run:control_updates_signal_selector) Shows the magnitude of the closed-loop updates applied to the drive signals for each drive signal (column) and sine tone (row).  Selecting a cell will display that drive signal and sine tone in the Drive Updates plot.


(sec:sine_run:data_display_groupbox)=
* [**Control Tone Selector**](#fig:sine_run:control_tone_selector) Selects the sine tone that will be displayed in the window that is created when the Create Window button is clicked.
* [**Control Channel Selector**](#fig:sine_run:control_channel_selector) Selects the control channel that will be displayed in the window that is created when the Create Window button is clicked.
* [**Create Window**](#fig:sine_run:create_window_button) Create a window to show the signal specified by the selected Control Channel and Control Tone
* [**Show All Control Channels**](#fig:sine_run:show_all_channels_button) Creates a display window for each control tone and control channel combination in the test and tiles them on the main monitor.
* [**Tile All Windows**](#fig:sine_run:tile_windows_button) Tile all open display windows across the main monitor
* [**Close All Windows**](#fig:sine_run:close_windows_button) Closes all existing visualization windows
