(sec:modal_definition:sampling_parameters_groupbox)=
* [**Samples per Acquire**](#fig:modal_definition:samples_per_acquire_display) Number of samples that the control process processes at a time. This will be equal to the Samples per Frame * (1 - Overlap Percentage / 100). This need not correspond to the read or write size of the data acquisition system as the control process acquisition is buffered.
* [**Sample Rate**](#fig:modal_definition:sample_rate_display) Sample rate in samples per second of the data acquisition hardware, for display only.  This is a global parameter and must be set in the Data Acquisition Setup tab.
* [**Nyquist Frequency**](#fig:modal_definition:nyquist_frequency_display) The Nyquist Frequency is the highest frequency that can be analyzed using frequency domain techniques.  It is the Sample Rate / 2.
* [**FFT Lines**](#fig:modal_definition:fft_lines_display) The number of frequency lines in the Fast Fourier Transform output, which is the number of frequency lines that will be in the Transfer Function and CPSD matrices.
* [**Frequency Spacing**](#fig:modal_definition:frequency_spacing_display) The frequency resolution of the measurement, computed by 1/Frame Time.
* [**Samples per Frame**](#fig:modal_definition:samples_per_frame_selector) Samples per measurement frame in the controller. The measurement frame is the "block" of data upon which the signal processing will be performed. This value will determine the window size. A larger value will result in more frequency lines in the FFT analysis. This need not correspond to the read or write size in the data acquisition system.
* [**Frame Time**](#fig:modal_definition:frame_time_display) Time to acquire each measurement frame in seconds. This is the Samples per Frame divided by the Sample Rate.


(sec:modal_definition:system_id_groupbox)=
* [**Averaging Type**](#fig:modal_definition:system_id_averaging_scheme_selector) Specifies how averaging is performed.  Linear averaging weights all measurement frames equally.  Exponential averaging weights more recent frames more heavily.
* [**Overlap Percentage**](#fig:modal_definition:system_id_overlap_percentage_selector) The percentage overlap used between measurement frames.  A 25% overlap means the last quarter of the previous measurement frame is used as the first quarter of the new measurement frame.
* [**Averaging Coefficient**](#fig:modal_definition:system_id_averaging_coefficient_selector) Weighting applied to the most recent average when Exponential Averaging is used
* [**FRF Technique**](#fig:modal_definition:system_id_frf_technique_selector) Technique to compute the Transfer Function. H1 averages noise on the response channels.
* [**Number of Averages**](#fig:modal_definition:system_id_frames_to_average_selector) The number of averages used to compute the frequency response functions.
* [**FRF Window**](#fig:modal_definition:system_id_transfer_function_computation_window_selector) The window function applied to the measurement frames when computing the transfer functions.  Rectangle: No window is used, all samples are weighted equally. Used for periodic signals or signals that start and end at zero in the measurement frame.  Hann: Window that weights the start and end of the frame to zero and the middle to one. Useful for Random excitation to reduce leakage.  Exponential: Window that weights the beginning of the frame more heavily than the end of the frame. Useful for impact testing where the test article's response doesn't decay by itself by the end of the measurement frame.
* [**Window value at frame end**](#fig:modal_definition:window_value_selector) Value of the exponential window at the end of the measurement frame, which is used to specify how quickly the exponential window decays.


(sec:modal_definition:triggering_groupbox)=
* [**Hysteresis Samples**](#fig:modal_definition:hysteresis_samples_display) Number of samples that the trigger channel must be below the Hysteresis level.  This property is read only and shown for the user's convenience.
* [**Pretrigger**](#fig:modal_definition:pretrigger_selector) Amount of time in the measurement frame before the trigger occurs.  The system retains a running buffer of recently acquired data looking for the trigger.  When the trigger is found, the specified percentage of the frame is data that occured before the trigger.  This is used to capture, for example, the entire transient of a shock, some of which may occur before the trigger depending on the trigger level.
* [**Trigger Channel**](#fig:modal_definition:trigger_channel_selector) Select the channel to use as a trigger.
* [**Wait for Steady State**](#fig:modal_definition:wait_for_steady_selector) Amount of time to wait for the measurement to achieve a steady state response prior to performing signal processing operations.
* [**Trigger Level (V)**](#fig:modal_definition:trigger_level_voltage_display) Level to trigger at in volts.  This property is read only and displayed for the user's convenience.
* [**Triggering Type**](#fig:modal_definition:triggering_type_selector) Type of trigger used for the analysis.  Free Run: No triggering is used.  First Frame: Triggering only starts the first measurement frame and then the measurement proceeds as if it were a Free Run.  Every Frame: The measurement waits for a trigger for every measurement frame.
* [**Acceptance**](#fig:modal_definition:acceptance_selector) Determines how measurement frames are accepted or rejected.  Accept All: Accepts all measurement frames  Manual: Allows the user to specify whether the recently obtained measurement frame should be accepted or rejected.  Autoreject...: Allows the user to load in a Python function to automatically accept or reject the measurement frame based off of arbitrary criteria.
* [**Trigger Level**](#fig:modal_definition:trigger_level_selector) Level to trigger at as a percentage of the range of the channel.
* [**Trigger Level (EU)**](#fig:modal_definition:trigger_level_eu_display) Level to trigger at in Engineering Units.  This property is read only and displayed for the user's convenience.
* [**Hysteresis Level**](#fig:modal_definition:hysteresis_selector) Level that the signal must return to prior to a new trigger being able to be accepted.  This ensures that the system must return to some nominal state prior to a new trigger being obtained.  Specified in percentage of the range of the channel.
* [**Hysteresis Level (V)**](#fig:modal_definition:hysteresis_voltage_display) Level that the trigger channel must fall below to achieve a subsequent trigger in volts. This property is read only and displayed for the user's convenience.
* [**Hysteresis Level (EU)**](#fig:modal_definition:hysteresis_eu_display) Level that the trigger channel must fall below to achieve a subsequent trigger in Engineering Units.  This property is read only and displayed for the user's convenience.
* [**Trigger Slope**](#fig:modal_definition:trigger_slope_selector) Slope of the trigger.  If the slope is Positive, it will look for a rising signal to trigger the measurement.  If the trigger slope is Negative, it will look for a falling signal to trigger the measurement.
* [**Hysteresis Time (s)**](#fig:modal_definition:hysteresis_time_display) Amount of time that the trigger channel must be below the Hysteresis level. This property is read only and is displayed for the user's convenience.
* [**Hysteresis Frame %**](#fig:modal_definition:hysteresis_length_selector) Percentage of the measurement frame that the signal must be below the Hysteresis value in order to accept a new trigger.  Useful for Burst Random excitation where you don't want to accidentally trigger midway through the burst.
