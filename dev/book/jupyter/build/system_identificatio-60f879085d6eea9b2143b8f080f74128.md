(sec:system_identification:parameters_groupbox)=
* [**Samples per Frame**](#fig:system_identification:samplesPerFrameSpinBox) Samples per measurement frame used in the system identification.  Some environments force system identification to use the same frame size as the signal processing performed in the environment.  If this field cannot be edited here, then check the Environment Definition tab for a similar property.
* [**Averaging Type**](#fig:system_identification:averagingTypeComboBox) Type of averaging used in the system identification.  Linear averaging weights each measurement frame equally.  Exponential averaging treats more recent averages with a higher weight.
* [**Noise Averages**](#fig:system_identification:noiseAveragesSpinBox) Number of measurement frames to acquire to analyze the noise level of the test.
* [**System ID Averages**](#fig:system_identification:systemIDAveragesSpinBox) Number of measurement frames to acquire to identify the system and compute transfer functions.
* [**Averaging Coefficient**](#fig:system_identification:averagingCoefficientDoubleSpinBox) Averaging coefficient used to weight the most recent measurement frame if exponential averaging is used.
* [**Estimator**](#fig:system_identification:estimatorComboBox) The estimator to use to compute transfer functions when performing system identification.
* [**Level**](#fig:system_identification:levelDoubleSpinBox) Root-mean-square voltage level to play to the shakers when computing system identification
* [**Ramp Time**](#fig:system_identification:levelRampTimeDoubleSpinBox) Time to ramp the system identification voltage to the test level.


(sec:system_identification:groupBox)=
* [**On Fraction**](#fig:system_identification:onFractionDoubleSpinBox) Fraction of the measurement frame that the burst random excitation is active for.
* [**Pretrigger**](#fig:system_identification:pretriggerDoubleSpinBox) Percentage of the measurement frame that is before the burst random excitation.
* [**Ramp Fraction**](#fig:system_identification:rampFractionDoubleSpinBox) Percentage of the burst that is used to ramp from zero to the test level.
* [**Signal Type**](#fig:system_identification:signalTypeComboBox) Excitation used for system identification.  Random and Burst random excitation are suitable for MIMO control problems.  Chirp and Pseudorandom should only be used for single-shaker excitation.
* [**Window**](#fig:system_identification:windowComboBox) Window function to apply to the data when computing transfer functions during system identification.
* [**Overlap**](#fig:system_identification:overlapDoubleSpinBox) Overlap to use between measurement frames when computing transfer functions.
* [**Bandwidth Minimum Frequency**](#fig:system_identification:lowFreqCutoffSpinBox) The lowest frequency content in the excitation signal used in system identification.
* [**Bandwidth Maximum Frequency**](#fig:system_identification:highFreqCutoffSpinBox) The highest frequency content in the excitation signal used in system identification.

(sec:system_identification:start_stop_groupbox)=
* [**Preview Noise**](#fig:system_identification:preview_noise_button) Starts the noise identification of the system identification process in preview mode.  No excitation will be applied to the shakers.  The preview will continue until stopped manually.
* [**Preview System Identification**](#fig:system_identification:preview_system_id_button) Starts the system identification process in preview mode with excitation applied to the shakers.  The preview will continue until stopped manually.
* [**Start**](#fig:system_identification:start_button) Starts the full system identification process, including noise characterization and transfer function computation.  Each step will stop automatically when the requested number of averages has been acquired.
* [**Stop**](#fig:system_identification:stop_button) Manually stops the system identification process.
