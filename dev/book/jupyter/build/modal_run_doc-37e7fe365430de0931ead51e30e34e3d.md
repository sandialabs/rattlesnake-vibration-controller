(sec:modal_run:acqusition_groupbox)=
* [**Preview Acquisition**](#fig:modal_run:preview_test_button) Starts the acquisition in Preview mode which will not save data to the disk nor will it stop automatically when the requested number of averages is reached.
* [**Start Acquisition**](#fig:modal_run:start_test_button) Starts the acquisition and stores data to the disk.  Acquisition will stop automatically when the requested number of averages is reached.
* [**Stop Acquisition**](#fig:modal_run:stop_test_button) Stops the currently active acquisition.
* [**Data File**](#fig:modal_run:data_file_selector) File to which modal data is written from Rattlesnake.  Note that writing modal data to a network drive can cause the user interface to hang if the files are large and the network is relatively slow.
* [**Select File...**](#fig:modal_run:select_file_button) Opens a file dialog to allow the user to select a file to which data will be saved.  For large tests, it is not recommended to write data directly to a network drive, as relatively slow network speeds may cause the user interface to hang while the file is being written.
* [**Auto-Increment**](#fig:modal_run:autoincrement_checkbox) Select this to automatically add a 4-digit number to the file name that will increment automatically.  This can be useful for roving hammer excitation where the user does not want to accidentally overwrite previous data.


(sec:modal_run:averaging_groupbox)=
* [**Average Count**](#fig:modal_run:current_average_display) Current number of averages acquired
* [**Total Averages**](#fig:modal_run:total_averages_display) Total number of averages that will be acquired during the test, after which data acquisition will shut down automatically if not in preview mode.
* [**Accept**](#fig:modal_run:accept_average_button) Manually accept the current measurement frame.  This button will be disabled unless Manual acceptance is specified.
* [**Reject**](#fig:modal_run:reject_average_button) Manually reject the current measurement frame.  This button will be disabled unless Manual acceptance is specified.


(sec:modal_run:window_groupbox)=
* [**New Window**](#fig:modal_run:new_window_button) Create a new data visualization window.
* [**New Window from Template...**](#fig:modal_run:new_from_template_combobox) Create a visualization window from a set of preset templates of commonly requested visualizations, such as drive point FRFs or reference autospectra.
* [**Tile**](#fig:modal_run:tile_layout_button) Tile all visualization windows
* [**Close All**](#fig:modal_run:close_all_button) Close all visualization windows.
* [**<< (Decrement Channels)**](#fig:modal_run:decrement_channels_button) Decrement channels in visualization windows by the specified number of channels, except for windows that are locked.
* [**>> (Increment Channels)**](#fig:modal_run:increment_channels_button) Increment channels in visualization windows by the specified number of channels, except for windows that are locked.
* [**Channel Increment**](#fig:modal_run:increment_channels_number) Select the number of channels to increment all windows by.  This is useful to quickly move through all channels in a test.


(sec:modal_run:dof_override_groupbox)=
* [**Degree of Freedom Override Table**](#fig:modal_run:dof_override_table) This table can be used during roving hammer testing, or other testing that involves changing the channel degrees of freedom, to change channel names during a test without needing to update the channel table and re-initialize the data acquisition system.  The user selects a channel to update and provides a new node number and new direction string.  Subsequently acquired data will have degree of freedom information updated in the channel table that gets stored to the disk with the data.
* [**Add Override**](#fig:modal_run:add_override_button) Adds an override to the channel table to change the degree of freedom associated with a given channel.  Useful for roving hammer or roving accelerometer testing.
* [**Remove Override**](#fig:modal_run:remove_override_button) Removes the selected channel override.

(sec:modal_run:auto_1)=
* [**Display Area**](#fig:modal_run:channel_display_area) New windows will be placed in this area, allowing flexible visualization of modal data during the test.
* [**Signal Type Selector**](#fig:modal_run:signal_selector) Select the type of data to look at.
* [**Channel Selector**](#fig:modal_run:response_coordinate_selector) Select the channel to look at.
* [**Reference Channel Selector**](#fig:modal_run:reference_coordinate_selector) Select the reference to look at.
* [**Data Display Selector**](#fig:modal_run:data_type_selector) Select how the data is displayed.
